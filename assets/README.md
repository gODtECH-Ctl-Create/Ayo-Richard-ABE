# Portfolio assets

## Profile photo

The hero profile card uses the image currently stored as:

`assets/gODtECH.png`

Keep the filename and path unchanged unless the hero card code is updated.

## Project screenshots

Each portfolio project gets its own folder under:

`assets/projects/<project-slug>/`

Use up to three screenshots per project:

`01.jpg`
`02.jpg`
`03.jpg`

The portfolio automatically cycles through the available screenshots every 1.8 seconds with a soft crossfade. If a project has no screenshots yet, its built-in visual placeholder remains visible.
